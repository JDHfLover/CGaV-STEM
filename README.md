# STEM-проєкт: Аналіз та обробка зображень за допомогою класичних методів фільтрації, сегментації та аналізу текстур

**Дисципліна:** Комп'ютерна графіка та візуалізація  
**Виконав:** Бобенко Сергій, група ІПЗ-23(08)  
**Формат виконання:** Індивідуально, Варіант 1 (Експертний рівень D1: 6 методів із 6 різних категорій, вибірка 100 зображень)

---

## 1. Технічне завдання (ТЗ)

1. **Тема:** Аналіз та обробка зображень реальних об'єктів за допомогою класичних методів фільтрації, гістограмної корекції, контурного аналізу, сегментації, морфологічної обробки та аналізу текстур.
2. **Вибірка зображень (`stem_dataset/`):** 100 зображень розміром $128 \times 128$ пікселів у 5 прикладних доменах (по 20 зображень на клас):
   - `aerial_runway` — аерокосмічні знімки аеродромів та злітно-посадкових смуг;
   - `urban_blocks` — аерофотознімки міської забудови та кварталів;
   - `biometric_fingerprint` — біометричні зображення папілярного узору відбитків пальців;
   - `satellite_river_forest` — супутникові знімки річкових русел та лісових масивів;
   - `historical_manuscript` — текстові об'єкти (рукописи та стародруки).
   Кожен клас представлений у 4 режимах зйомки: низький рівень шуму ($\sigma=6$), гаусів шум ($\sigma=22$), імпульсний шум «сіль і перець» ($p=8\%$) та знижений контраст із нерівномірним освітленням.
3. **Реалізовані методи (6 методів із 6 категорій, усі реалізовані вручну без вбудованих функцій OpenCV/scikit-image та відмінні від ЛР №5–6):**
   - **Метод 1 (`bilateral`)** — *Категорія: Ретушування та шумоподавлення зі збереженням контурів* — Білатеральний фільтр ($5 \times 5$, $\sigma_s = 2.0$, $\sigma_r = 28.0$).
   - **Метод 2 (`clahe`)** — *Категорія: Гістограмна корекція* — Адаптивне гістограмне вирівнювання з обмеженням контрасту (CLAHE, сітка тайлів $4 \times 4$, `clip_limit = 2.5`) із білінійною інтерполяцією між тайлами.
   - **Метод 3 (`sobel`)** — *Категорія: Контурний аналіз* — Градієнтний оператор Собеля ($G = \sqrt{G_x^2 + G_y^2}$).
   - **Метод 4 (`otsu`)** — *Категорія: Сегментація зображень* — Автоматична глобальна порогова сегментація за критерієм Оцу (максимізація міжкласової дисперсії $\sigma_B^2(t)$).
   - **Метод 5 (`morphology`)** — *Категорія: Морфологічна обробка* — Сірошкальна ерозія, дилатація, відкриття, закриття та симетричне морфологічне відкриття-закриття $\frac{1}{2}(\gamma_B(I) + \varphi_B(I))$.
   - **Метод 6 (`lbp_glcm`)** — *Категорія: Аналіз текстур* — Карта локальних бінарних шаблонів (LBP) та матриця спільної появи рівнів сірого (GLCM) з обчисленням текстурних ознак Хараліка (контраст, гомогенність, енергія, кореляція).
4. **Метрики якості та порогові критерії коректності (C1):**
   - Середньоквадратична похибка (**MSE**), пікове відношення сигнал/шум (**PSNR**, дБ), індекс структурної подібності (**SSIM**), інформаційна ентропія Шеннона (**H**, біт), коефіцієнт Жаккара (**IoU**) та **F1-міра**.
   - Цільові пороги валідації: $\text{PSNR}_{\text{bilateral}} \ge 22.0\text{ дБ}$, $\text{SSIM}_{\text{bilateral}} \ge 0.70$, $\text{PSNR}_{\text{morphology}} \ge 20.0\text{ дБ}$, $\text{IoU}_{\text{otsu}} \ge 0.55$, $\text{F1}_{\text{sobel}} \ge 0.50$.

## 2. Структура проєкту

```text
.
├── stem_project.py        # Основний модуль і CLI-застосунок STEM-проєкту (6 методів + метрики)
├── stem_config.json       # Конфігураційний файл параметрів методів, вибірки та порогів
├── test_stem.py           # Автотести (C1, C2, C3) з ручною перевіркою на матрицях 3x3 та 5x5
├── README.md              # Документація проєкту та інструкція запуску
├── META-USAGE.md          # Декларація використання генеративного ШІ
├── STEMReport.odt         # Звіт зі STEM-проєкту у форматі OpenDocument Text
├── STEMReport.pdf         # Звіт зі STEM-проєкту у форматі PDF
├── stem_dataset/          # Вибірка зі 100 вхідних зображень (128x128) та еталонів (references/)
└── stem_results/          # Збережені оброблені зображення, metrics.csv, metrics.json та графіки
```

## 3. Інструкція запуску з нуля

### Вимоги до середовища
- Python 3.10+
- Базові пакети: `numpy`, `Pillow`, `matplotlib`

### Крок 1. Запуск автоматизованих модульних тестів (критерії C1, C2, C3)
```bash
python3 test_stem.py
```

### Крок 2. Повний запуск STEM-проєкту на вибірці зі 100 зображень (усі 6 методів)
```bash
python3 stem_project.py --config stem_config.json
```
Під час першого запуску програма автоматично створює вибірку `stem_dataset/` (100 зображень з фіксованим `seed=42`), виконує всі активні методи, зберігає вихідні зображення у `stem_results/<method>/`, записує метрики у `stem_results/metrics.csv`, `stem_results/summary_by_method.csv` та `stem_results/metrics.json`, а також генерує підсумкові графіки `stem_fig1..4.png`.

### Крок 3. Запуск окремого методу або зміна конфігурації через аргументи CLI
```bash
python3 stem_project.py --config stem_config.json --method bilateral
python3 stem_project.py --config stem_config.json --method clahe --output-dir stem_results_custom
```
